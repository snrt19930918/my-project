二装施工过程管理 · Web 管理后台 · 主规格草案

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。本原型为「智慧建筑二装施工过程管理系统」的 Web 管理后台（系统管理员端），与小程序端原型 fitout-process 共用同一套业务数据口径与设计基底。

当前方案

  • 原型意图：还原 Web 管理后台核心管控链路，覆盖登录、运营概览、项目点位管理、账号管理、服务单全量管理与工作推进、统计报表与系统配置，共 13 页（新增「流程设计器」）；业务事实与小程序端 fitout-process 及 PRD V1.2 保持一致。
  • 使用场景：商业广场、办公楼场景下，内部运营与管理人员对二装服务业务进行全量监控、配置与审计的桌面端后台；P0 阶段补充项目经理 / 报价员 / 财务 / 代办 / 绘图员的角色视角模拟。
  • 当前表达：以桌面端「左侧导航 + 顶栏 + 内容区」为壳，通过 hash 路由 #page= 切换页面；右上角可切换模拟角色与跳页；用真实感示例数据演示项目、账号、23 条服务单与报表；风格与小程序端一致（IBM 基底 + 主色 #1677FF + 圆角 8px）。

事实与输入

用户确认事实

  • 双端系统：微信小程序（客户 + 5 类员工）+ Web 管理后台（系统管理员只读 + 5 类员工角色模拟）；本原型做Web 管理后台 13 页。
  • 13 页划分（7 大类展开）：登录、概览驾驶舱、项目点位（列表/详情配置）、账号管理（员工账户/业主信息）、服务单全量管理（列表/详情）、统计报表、系统配置（流程编排/流程设计器/岗位配置/通知与超时）。
  • 新增「流程设计器」为独立草稿式流程引擎编辑台：可自定义流程、节点表单字段与处置权限，用于后期扩展与编辑；发布结果仅在设计器版本与预览内生效，不接管现有 10 节点运行时流程。
  • 节点授权模型：节点不直接绑定「处置岗位」，改为「处置权限」；系统按「用户岗位是否绑定该节点处置权限」判断是否有处置权，权限名称按处置节点操作权限命名（如「审核处置权」）。
  • 节点模型：创建 → 评估指派（可选，仅项目未配置跟进人员时触发）→ 图纸深化 → 审核 → 确认合同 → 审图（如选）→ 施工 → 申报（如选）→ 验收办结；合同收款为并行支线。
  • 服务单持久状态 5 类：服务中（创建即进入）、待确认、已完成、已结束、已终止；「待处理」是当前节点处理人可见的派生处置态。设计基底沿用 IBM 主题；主色 #1677FF，圆角 8px；状态色（待处理 #FAAD14、服务中 #1677FF、待确认深橙描边 #D46B08、已完成 #52C41A、已结束紫 #531DAB、已终止 #F5222D）。
  • 与小程序端 fitout-process 共用示例数据口径：6 个项目、23 条服务单、6 类角色、10 个节点、合同与收款、结束服务会签。

当前假设

  • 示例数据（6 个项目、12 名员工、7 名业主、23 条服务单、统计数字）为真实感虚构数据，与小程序端同源。
  • 无真实鉴权，登录后用「系统管理员」只读视角进入后台；通过右上角角色下拉切换项目经理 / 报价员 / 财务 / 代办 / 绘图员视角，模拟节点处置权限。
  • 系统管理员只读，仅可对共享池（待分配 / needAssign）工单执行分派；员工角色按当前节点处理角色与岗位权限门控操作。
  • 合同金额默认脱敏；仅财务视图与报价员「确认合同」表单可见完整金额，收款比例对所有员工可见。
  • 地图点选、文件上传、报表导出为静态示意（非真实地图 / 真实上传 / 真实导出）；节点推进与收款在本地状态中演示，不写入后端。

原型范围

本次呈现（Web 管理后台 13 页）

  • 登录 1 页：系统管理员账号密码登录。
  • 概览驾驶舱 1 页：核心指标卡（含待确认会签数）、趋势图、预警待办、服务类型占比。
  • 项目点位 2 页：建筑项目列表（搜索 / 状态筛选 / 地图定位入口）、项目详情与专属团队 / 岗位配置；未配置跟进人员的项目下单后进入共享池。
  • 账号管理 2 页：员工账户管理（增删改 / 停用 / 岗位权限）、业主信息管理（信息修正 / 账号状态）。
  • 服务单全量管理 2 页：服务单列表（6 状态 / 节点 / 项目 / 共享池筛选、角色标签、收款状态列）、服务单详情（角色门控工作推进、全流程进度、合同与并行收款、节点文件、结束服务会签、操作历史）。
  • P0 业务能力：评估指派与共享池分派、合同两次签订（仅施工 / 仅代办 / 完整施工代办）、合同总价选填与自动大写、工作量采用绘图员版本或最终确认版、多次累计收款、全部合同 100% 且服务完结才办结、结束服务原因必填与会签、金额脱敏、撤回。
  • 统计报表 1 页：多维度统计图表与导出入口，在途 / 完结按真实数据统计。
  • 系统配置 4 页：流程编排（10 节点处置权限 / 三类服务分支 / 合同收款并行支线 / 节点级超时阈值）、流程设计器（流程引擎编辑台：服务分支可视化编排 / 节点增删排序 / 节点表单字段设计 / 处置权限绑定 / 超时与通知引用 / 校验与版本发布演示）、岗位配置（自定义岗位 / 绑定功能权限）、通知与超时（8 类事件 / 节点 × 事件渠道 / 收件人 / 模板 / 频次）。

本次不呈现

  • 业务导入管理、独立财务工作台、全节点版本管理中心、智能 Agent 管理（PRD 后续规划功能域）；以及流程引擎真实执行与持久化、BPMN 全量规范 / 复杂网关表达式、设计器表单与订单详情表单的真实联动（本期设计器为草稿式演示，发布结果不接管运行时流程）。
  • OpenID 绑定管理、敏感数据加密配置、访问日志等账户安全子项。
  • 真实地图服务、真实微信授权、真实文件上传 / 预览、报表真实导出、后端接口与鉴权。
  • 业主脱敏假号码的修正审计、项目团队配置持久化、报表自定义筛选等 P1 / P2 项。

设计基底与原型特有调整

  • 采用的 DESIGN.md：src/themes/ibm/DESIGN.md
  • 继承方式：以 IBM Carbon 为企业蓝、浅色、B2B 管理系统的视觉骨架，桌面端侧边栏布局。

  • 新增「流程设计器」沿用 IBM 卡片化工作台：左侧分支与节点库、中部画布（节点卡片 + 1px 描边连线、可选节点虚线、合同收款并行泳道）、右侧属性面板；选中节点使用主色 #1677FF 描边与 #E6F4FF 底色。

权限差异

  • 后台管理权限与节点处置权限并列，由「岗位配置」绑定、互不隐含：业务管理员可访问业务管理（项目点位 / 服务单管理）与统计报表，查看与管理全量业务数据；系统管理员可访问账号管理与数据与配置（流程编排 / 流程设计器 / 岗位配置 / 通知与超时）。
  • 未开通业务管理员的账号登录后仅可查看、处理本人相关服务单（当前处理人、项目专属团队、合同提交 / 接收、收款记录、会签参与、回退处置人）；概览驾驶舱仅展示本人相关数据。概览驾驶舱本身不设访问门控；业务管理员查看全局数据。
  • 系统管理员账号（只读视角）在服务单详情仅可执行共享池分派；节点处置权仍按岗位节点权限判断，后台权限不放大节点操作。
  • 绘图员：创建、图纸深化；项目经理：评估指派、审核、施工、验收、结束服务会签；报价员：确认 / 补签合同、结束服务会签；财务：合同收款并可查看完整金额；代办：审图、申报凭证。
  • 员工仅在「当前节点处理角色」匹配时显示对应操作；任意员工可在自己处置的节点发起结束服务，符合条件可撤回。
  • 状态标签按查看者解析：服务单创建即「服务中」；员工仅在自己为当前节点处理人时看到派生「待处理」，其余在途服务单显示「服务中」；财务视角统一按「服务中 / 待收款 / 已收讫」口径展示，且任一财务权限用户均可更新收款进度；系统管理员只读视角显示「服务中」，不展示「待处理」。
  • 合同金额默认脱敏，仅财务视图与报价员确认合同表单可见完整金额；收款比例对所有员工可见。
  • 业主手机号等敏感信息在账号管理 / 服务单详情中脱敏展示（如 138****2211）。
  • 员工账户仅由系统管理员增删改与停用；停用后退回共享池。
  • 节点处置权由「岗位配置」决定：系统按员工岗位是否绑定该节点「处置权限」判断是否可处置，而非直接绑定岗位。

状态与空状态

  • 服务单持久状态 5 类：服务中（浅蓝，创建即进入）、待确认（深橙描边，结束服务会签中）、已完成（浅绿）、已结束（浅紫）、已终止（浅红）；「待处理」（浅橙）是当前节点处理人可见的派生处置态。
  • 财务视角：所有财务权限用户均按「服务中」查看，列表筛选不提供待处理；合同已收齐的在途服务单显示「已收讫」，未收齐显示「待收款」，且不叠加「待我处理」标签。
  • 员工视角：待处理仅在本人为当前处理人时展示，其余在途服务单显示「服务中」，状态筛选以解析后状态为准；管理员只读视角不展示「待处理」。
  • 补签新增节点位置早于当前节点时，服务单回退至新增节点（处置人取合同所选接收用户），按完整流程顺序办完后自动回到原节点并保留处置进度；晚于当前节点的正常追加，不回退；回退链内不选下一节点处理人，回流后恢复常规选人。
  • 处于合同收款节点的服务单，服务支线进度显示「服务支线已完结」，节点文件同时展示已完成节点与合同收款记录。
  • 项目状态 3 类：启用、停用、临时。
  • 账号状态 2 类：启用、停用。
  • 列表无结果：显示「暂无匹配的服务单」空态。
  • 合同未确认 / 无节点文件 / 报表无数据：显示对应空态占位。
